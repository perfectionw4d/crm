מדריך מלא ב-7 שלבים:

  1. כנס ל-console.cloud.google.com
  2. צור פרויקט חדש בשם "שקוף בחזית CRM"
  3. הפעל: Calendar API, Tasks API, People API
  4. Credentials → Create OAuth 2.0 Client ID
  5. Application type: Web application
    Redirect URI: http://localhost:3000/auth/callback
  6. העתק Client ID ו-Client Secret לקובץ .env
  7. הפעל מחדש את start.bat ולחץ "התחבר עם Google"
