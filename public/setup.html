אתר WordPress

האם יש לך אתר WordPress? זה מאפשר ללקוחות לצפות ולחתום על מסמכים.

🤔 למה זה שימושי?
כשתיצרי הצעת מחיר או הזמנת עבודה, המערכת יכולה לפרסם אותה באתר שלך כדף אינטרנט. הלקוח מקבל קישור, פותח את הדף, רואה את ההצעה — ויכול לחתום דיגיטלית ישירות.
✅
כן, יש לי אתר
⏭️
לא עכשיו
✅ מצוין! צריך להתקין תוסף קטן באתר שלך שמחבר אותו ל-CRM.
1
הורידי את תוסף ה-CRM בלחיצה על הכפתור למטה.
2
בלוח הבקרה של WordPress: תוספים → הוסף תוסף חדש → העלה תוסף
בחרי את הקובץ שהורדת והפעילי אותו.
3
לאחר ההתקנה: הגדרות → CRM Integration
הזיני שם API Key — כלשהו שתבחרי (למשל: 12345 או מילה שאת בוחרת).
4
הכניסי את אותו ה-API Key ואת כתובת האתר בשדות למטה:
כל סיסמה שתבחרי — תהיה זהה כאן ובתוסף
